# 🏠 Smart Home IoT System

## 📌 Overview
This project demonstrates a smart home IoT system developed using Cisco Packet Tracer.  
The system connects smart devices with a mobile device to allow monitoring and remote control through IoT technology.

---

## 💡 Features
- Smart device communication  
- Remote monitoring using mobile device  
- IoT network simulation  
- Automated smart home environment  

---

## 🛠 Technologies Used
- Cisco Packet Tracer  
- IoT Devices  
- Networking Concepts  
- Mobile Device Integration  

---

## 📱 System Functions
- Control smart home devices remotely  
- Monitor connected IoT devices  
- Simulate smart home communication network  

---

- Built the network simulation using Cisco Packet Tracer
